# Bro

Wait, I don't understand where you've got to here. Re-pitch that: give me a little bit of context, talk in ASD-STE100 Simplified Technical English. Restate your last message. Stop using jargon and speak coherently. State it more simply and concisely, like one human talking to another.

## Instructions

When this skill is invoked:

1. Restate the **previous assistant message** (not the user's message).
2. Give a little context first so the reader knows what you are talking about.
3. Use **ASD-STE100 Simplified Technical English**:
   - Short sentences.
   - Common words.
   - One idea per sentence.
   - No jargon. If a technical word is necessary, explain it in plain words.
4. Write like one person talking to another — clear, direct, human.
5. Be concise. Do not add new technical content. Do not start new work.
